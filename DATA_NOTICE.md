# Source data note

The Rust lookahead code includes tables reconstructed from an owned Splatoon 3 11.3.0 copy, including level settings, stage metadata, and weapon candidate metadata. These are version-specific research inputs. No game executable, RomFS pack, packet capture, key, or random table is distributed here.

The MIT license in [LICENSE](LICENSE) covers the repository's original code and the adapted devcontainer example. It does not claim ownership of Nintendo's underlying game or grant rights to third-party game content.
